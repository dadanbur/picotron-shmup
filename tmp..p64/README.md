# Picotron Shmup Tutorial

A small shoot'em up (SHMUP) project developed with **Picotron** as a learning exercise.

The goal of this repository is to follow the excellent **PICO-8 SHMUP Tutorial** by **Christian from Lazy Devs Academy** ([@Krystman](https://github.com/Krystman)), while adapting every step to **Picotron**.

Rather than creating a direct port, this project explores how the same concepts, techniques, and game architecture can be implemented using Picotron's features and workflow.

## Purpose

This repository is intended for:

- Learning Lua programming in Picotron.
- Exploring Picotron's API and development workflow.
- Understanding the fundamentals of SHMUP development.
- Documenting the differences between PICO-8 and Picotron.

If you're learning Picotron and are looking for practical examples, you may find this repository useful.

## Differences from the original tutorial

This project follows the overall structure of the tutorial but adapts it to **Picotron**, which offers:

- Higher resolution
- A filesystem-based workflow
- More advanced Lua features
- Different APIs and capabilities
- A modern development environment

Whenever necessary, implementation details differ from the original tutorial while keeping the same learning objectives.
